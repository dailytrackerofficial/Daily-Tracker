# Daily Tracker — Organize • Achieve • Grow

> Your all-in-one productivity OS. Manage tasks, goals, habits, projects, notes, and analytics — all in one beautiful dashboard.


## ✨ Features

### 📊 Dashboard
- Real-time productivity statistics
- Weekly performance chart
- Recent activity feed
- Quick action buttons
- Today's habits and upcoming tasks preview

### ✅ Tasks
- Create, edit, and delete tasks
- Set due dates, priorities (High/Medium/Low), and tags
- Mark tasks as complete
- List view and Kanban board view
- Search and filter by status/priority

### 🎯 Goals
- Set long-term goals with deadlines
- Track progress with percentage slider
- Visual progress bars
- Goal completion stats

### 🔥 Habits
- Build daily habits with check-ins
- Track current and longest streaks
- Completion rate analytics
- 30-day mini grid view
- Heatmap visualization of activity

### 📁 Projects
- Organize work into structured projects
- Status tracking (Planning/Active/Completed)
- Color-coded project cards
- Task association

### 📝 Notes
- Rich text editing (bold, italic, lists)
- Auto-save functionality
- Search notes by title/content
- Clean, distraction-free editor

### 📅 Calendar
- Monthly calendar view
- Task and goal deadlines displayed
- Quick overview of upcoming deadlines
- Today highlighting

### 📈 Analytics
- Task completion trends
- Habit completion rate chart
- Performance rings (Task/Habit/Goal/Overall)
- Priority breakdown
- Goal progress summary

### ⚙️ Settings
- Light/Dark theme toggle
- Custom accent colors
- Profile customization
- Data export/import (JSON)
- Reset application option

## 🚀 Getting Started

### Prerequisites
- Any modern web browser (Chrome, Firefox, Safari, Edge)
- No installation or backend required!

## 💾 Data Storage

All data is stored locally in your browser using `localStorage`. Your information never leaves your device unless you manually export it.

### Data Persistence
- Tasks, Goals, Habits, Projects, Notes — all saved automatically
- Dark/light theme preference remembered
- Sidebar collapsed state preserved
- Activity log of your last 50 actions

### Backup & Restore
- **Export**: Download all data as JSON file
- **Import**: Restore from previous backup
